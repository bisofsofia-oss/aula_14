# Calculadora em C#

Uma aplicação de calculadora desenvolvida em **C#** que realiza operações matemáticas básicas de forma simples e intuitiva.

## Funcionalidades

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* Validação de entradas
* Exibição do resultado no console

## Tecnologias Utilizadas

* C#
* .NET

## Como Executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/bisofsofia-oss/aula_14
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd SEU_REPOSITORIO
   ```

3. Execute a aplicação:

   ```bash
   dotnet run
   ```

## Exemplo de Uso

```text
Escolha uma operação:
1 - Soma
2 - Subtração
3 - Multiplicação
4 - Divisão

Digite o primeiro número: 10
Digite o segundo número: 5

Resultado: 15
```
